## Projetos em destaque

### EstoqueCars

Sistema para gerenciamento de estoque de veículos, com foco em cadastro, visualização, organização e controle das informações.

**Tecnologias:** React, Python, Flask, Firebird SQL.

**Destaques do projeto:**

- Interface web para consulta e gerenciamento de veículos.
- Backend com rotas para integração entre sistema e banco de dados Firebird.
- Organização de informações como veículos, vendas, reservas e usuários.
