Sou desenvolvedor Full Stack em formação, com foco em **React, Python, Flask e SQL**. Construo projetos para desenvolver minha prática na criação de interfaces, na implementação de backend e na integração com bancos de dados.

Busco oportunidades para contribuir com projetos de software, aprender com o time e evoluir como desenvolvedor.

## Projetos em destaque

### EstoqueCars | Gestão de estoque de veículos

Sistema para centralizar o cadastro, a consulta e a organização de veículos, vendas, reservas e usuários.

**Stack:** React · Python · Flask · Firebird SQL

**O que o projeto reúne:**

- Interface web para consulta e gerenciamento de veículos.
- Backend com rotas para integrar a aplicação ao banco de dados Firebird.
- Organização das informações de estoque e das operações de venda e reserva.

O projeto conecta **frontend, backend e persistência de dados** em um mesmo contexto de negócio.
